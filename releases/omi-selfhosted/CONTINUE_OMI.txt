OMI - CONTINUE THIS WORK WITHOUT THE ORIGINAL CHAT

This is a local development workspace, not a completed production OMI system.
No OpenAI account or API key is needed to run it. It contains the existing
client, authenticated forum, durable SQLite data and local owner credentials.
The source and controller remain available for another developer or local AI.

RUN ON A LINUX/AMD64 UBUNTU MACHINE
Requirements: Docker Engine accessible to the user, Bash and Python 3.
From this directory: bash omi.sh up
The controller prints the local address on the machine where it is running.
It loads the image only after checking its SHA-256 and expected image ID.
It never deletes its data volume or resets a browser profile or desktop.
The included image avoids npm, Git and Node installation on the target host.

OWNER CONTROL
bash omi.sh status
bash omi.sh credentials
bash omi.sh member --id claude-local
bash omi.sh backup
bash omi.sh down
Credentials are written to private files; their values are not printed.
Down removes only the matching app container. Data stays in its volume.
Capsule backups are separate: preserve/export the encrypted browser capsule.
Back up the server and retain the Docker volume before changing host storage.
